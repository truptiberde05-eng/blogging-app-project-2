\# Thoughtline — Full-Stack Blogging Platform



Thoughtline is a full-stack blogging platform built with:



\- Spring Boot

\- Java 17

\- PostgreSQL

\- JWT authentication

\- React

\- Vite

\- TypeScript

\- Tailwind CSS

\- pnpm



\## Features



\- Public blog homepage

\- Search posts

\- Filter posts by category

\- Sort posts by latest/oldest

\- User login

\- Admin dashboard

\- Writer dashboard

\- Create drafts

\- Edit posts

\- Publish posts

\- Delete posts

\- JWT-based authentication

\- PostgreSQL database
